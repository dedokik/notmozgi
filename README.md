# NotMozgi

Заметки для планшета: текст + холст (схемы стилусом), календарь с быстрыми событиями,
закрепление заметок и дат. Работает офлайн, синхронизируется через Supabase.

Сделано под **Xiaomi Pad 6** и стилус: крупные зоны нажатия, булавка в один тап,
сдвиг вьюпорта под панель Gboard.

Живёт здесь: **https://not.mozgi.workers.dev**

---

## Разработка

```bash
npm install
npm run dev      # http://<ip-ноутбука>:5173 — открывать с планшета по Wi-Fi
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр собранного dist/
```

## Деплой

Cloudflare подключён к этому репозиторию и собирает его сам:

- build command: `vite build`
- output directory: `dist`
- ветка: `main`

То есть достаточно `git push` — дальше всё происходит само, примерно через минуту.
Локально `npm run build` делает ровно то же самое, что и Cloudflare.

## Ключи Supabase

Два равноценных способа, выбирай любой:

1. **Без пересборки** — вписать в `public/config.js` и запушить:

```js
window.__NOT_CONFIG__ = {
  supabaseUrl: 'https://xxxx.supabase.co',
  supabaseAnonKey: 'eyJhbGciOi...',
}
```

2. **Через переменные окружения** — задать `VITE_SUPABASE_URL` и
   `VITE_SUPABASE_ANON_KEY` в настройках проекта Cloudflare (или в `.env`
   для локальной разработки, см. `.env.example`).

Без ключей приложение полностью рабочее — данные лежат в IndexedDB на устройстве.

Перед первым включением синхронизации один раз выполни `supabase/schema.sql`
в SQL Editor (файл идемпотентный, можно запускать повторно).
После обновлений прогони его ещё раз: добавились колонки `notes.draw_data`
(рисунок поверх текста) и `notes.deleted` (мягкое удаление — чтобы удаление
разъезжалось по устройствам). Без них всё работает локально, просто эти данные
не уедут в облако.

## Supabase

| Локально (Dexie) | Облако (Supabase) |
| --- | --- |
| `notes` (+ `is_pinned`, `note_type`, `canvas_data`) | `notes` |
| `events` (+ `is_pinned`) | `events` |
| `dimensions`, `links`, `chunks`, `pixels` | те же таблицы |
| `settings` | только локально |

Конфликты решаются по содержимому: побеждает сторона, которую меняли последней,
локальная правка никогда не затирается молча. Если в облаке осталась старая схема
(без `is_pinned` / `note_type` / `canvas_data`), синк не падает — работает на базовых
полях и пишет подсказку в журнал (вкладка «Диагностика»).

## Структура

```
src/
  App.jsx                    список, редактор, календарь, граф, карта
  lib/db.js                  Dexie: схема v1–v5, пиннинг, события, сиды
  lib/supabase.js            двусторонний синк + деградация на старой схеме
  lib/chunks.js              авто-чанкинг (оценка часов / дни до дедлайна)
  lib/dates.js               парсинг «дедлайн: 30.09», «завтра», «в пятницу»
  lib/notify.js              локальные напоминания
  components/CanvasBoard.jsx холст-доска: маркер, ластик, блоки, стрелки, текст
  components/DrawLayer.jsx   рисунок стилусом поверх текста заметки
  components/GraphView.jsx   граф всех заметок: хабы измерений + рисование
  components/NoteCard.jsx    карточка с булавкой

```

## Данные

Всё лежит в IndexedDB, база `not-dark-os`. `is_pinned` хранится как `0/1`, а не `boolean`:
IndexedDB не умеет индексировать boolean, и запись с `true` в индексируемом поле ломает таблицу.

Миграция со старой версии автоматическая (Dexie v4 → v5): существующие заметки получают
`is_pinned = 0`, `note_type = 'text'`, ничего не удаляется.

## Полезное

- **Дедлайн из текста**: `дедлайн: 30.09`, `завтра`, `в пятницу` → появляется в календаре.
- **Оценка**: `оценка: 6ч` → кнопка «Разбить на чанки» раскидывает часы по дням.
- **Привычка**: слово «ежедневно» → чекбокс на каждый день.
- **Поиск**: поле сверху списка — ищет по названию и по тексту заметки.
- **Бэкап**: кнопка «⤓ Экспорт данных» в сайдбаре — скачивает все заметки, события,
  связи и чанки в один JSON. Данные живут в браузере, так что иногда это стоит делать.
- **Связи**: `[[Название заметки]]` в тексте или ручная связь в редакторе.
- **Граф**: показывает все заметки сразу, а не одну. У каждого измерения свой узел-хаб,
  и все его заметки соединены с ним — то есть связи внутри измерения видно всегда,
  даже без `[[ссылок]]`. Чипы «Все / Я / Учёба / Работа» переключают граф на одно
  измерение (у каждого свои позиции узлов и свой рисунок). Поверх графа можно
  рисовать (✏️), узлы двигаются, положение и рисунок запоминаются.
- **Холст**: заметка → тип «🎨 Доска». Двумя пальцами — масштаб, «✋» — двигать.
- **Рисовать поверх текста**: в текстовой заметке кнопка «✏️ Рисовать» — текст остаётся
  видимым, сверху можно писать стилусом (пометки, обводки, стрелки). Штрихи хранятся
  в `draw_data` и синхронизируются.
- **Supabase free tier засыпает** после ~7 дней без запросов — в `.github/workflows/`
  лежит keep-alive пинг (секреты `SUPABASE_URL`, `SUPABASE_ANON_KEY`).
